# Changelog

## 0.1.0 — first release

- **Show flow** on any function, method or class (CodeLens, right-click, Ctrl+Shift+Alt+F,
  Command Palette): a panel of cards with arrows numbered in the order calls are written.
- Explore from any card: **Calls**, **Called by**, **Used by**, and **Extends** on classes.
  Class cards list their members; arrows leave from the exact member row.
- Readable at scale: at most 12 new cards per expansion plus a "+N more" card, hover to light up a
  flow, search, minimap, Back/Forward history, keyboard navigation.
- **Explain** a card or a path in plain language through GitHub Copilot (asks first, sends only
  the chosen code, off in untrusted workspaces).
- Copy the graph as a Mermaid diagram; doc comments on cards; a Get Started walkthrough.
- Follows light, dark and High Contrast themes.
- Tested with TypeScript, JavaScript and Python.
