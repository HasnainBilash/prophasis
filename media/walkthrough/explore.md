# Explore one step at a time

| Button          | Shows                                  |
| --------------- | -------------------------------------- |
| **Calls →**     | what this function calls, to the right |
| **← Called by** | what calls it, to the left             |
| **Used by**     | functions and classes that refer to it |
| **Extends**     | parent and child types (classes)       |

- Click a card to jump to its code.
- On a class card, hover a member row for **←** and **→** buttons. Arrows then
  leave from that exact row.
- Click a lit button again to hide what it showed.
- **← →** in the toolbar go back and forward between starting points.
