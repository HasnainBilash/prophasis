# Show the flow

Above every function, method and class you'll see a small **Show flow** link.

```ts
Show flow
async placeOrder(cart: Cart): Promise<string> {
```

Click it. A panel opens beside your code with the function as the **start
card** (it glows) and an arrow to everything it calls.

Other ways to start: right-click inside a function and choose
**Prophasis: Show Flow**, or press **Ctrl+Shift+Alt+F** (**Cmd+Shift+Alt+F** on
a Mac).
